# Data Model: Open-Tethyr Rust Toolkit Architecture

**Branch**: `001-rust-toolkit-architecture` | **Date**: 2026-03-12

## Entity Relationship Overview

```
AgentConfig (YAML input)
  ├── AgentDefaults (1:0..1) - global defaults
  └── AgentDefinition (1:N) - agent entries
        └── EndpointDefinition (1:N) - endpoint entries

    ── [ConfigMerger] ──▶

AgentExchangeDocument (JSON output)
  └── AgentExchangeRecord (1:N) - one per agent
        ├── Agent (1:1) - identity
        ├── Endpoint (1:N) - reachability
        ├── Capabilities (1:0..1)
        ├── Schema (1:0..1)
        ├── Limits (1:0..1)
        ├── Security (1:0..1) ── OAuthEndpoints (1:0..1)
        └── Extensions (1:0..1) - arbitrary JSON

CacheEntry
  ├── AgentExchangeDocument (1:1) - cached payload
  └── CacheMetadata - TTL, timestamps, domain

PolicyConfig
  ├── DomainLockingPolicy (1:0..1)
  └── RateLimitConfig (1:1)

CacheHierarchy
  ├── MemoryCache (local)
  └── RootCache (upstream, discovered via DNS)
```

## Core Entities

### AgentExchangeRecord

The primary AX protocol data unit. One record per agent, following AX 1.0 RFC structure.

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| record_type | String | Yes (default "AX") | Must be exactly "AX" |
| version | String | Yes (default "1.0") | Must be "1.0" for MVP |
| agent | Agent | Yes | Must contain valid name, description, provider |
| endpoints | Vec\<Endpoint\> | Yes | At least 1 endpoint required |
| capabilities | Capabilities | No | Optional agent capabilities |
| schema | Schema | No | Optional input/output schema |
| limits | Limits | No | Optional rate/size limits |
| security | Security | No | Optional OAuth/security config |
| extensions | JSON Value | No | Arbitrary extension data |

**Validation rules**:
- record_type must be "AX" (reject otherwise)
- version must be "1.0" (warn and skip for unsupported versions)
- agent.name must be non-empty
- agent.description must be non-empty
- agent.provider must be non-empty
- endpoints must have at least one entry
- Each endpoint.auth entry must be from: OIDC, OAuth2, mTLS, JWT, API_KEY

### AgentExchangeDocument

Container for multiple AX records. This is the top-level structure served at well-known URIs.

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| records | Vec\<AgentExchangeRecord\> | Yes | At least 1 record |

### Agent

Identity information for a single agent. No endpoints (those are at record level per AX RFC).

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| name | String | Yes | Non-empty, 1-100 characters |
| description | String | Yes | Non-empty, 1-500 characters |
| provider | String | Yes | Non-empty, 1-100 characters |

### Endpoint

A network location where an agent can be reached.

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| protocol | Protocol (enum) | Yes | One of: rest, graphql, mcp, a2a, or custom string |
| url | String | Yes | Valid HTTPS URL |
| auth | Vec\<String\> | Yes | At least 1 auth method from supported set |
| content_type | String | No | MIME type (default: application/json) |

### Protocol (enum)

| Variant | Serialized As | Description |
|---------|--------------|-------------|
| Rest | "rest" | RESTful HTTP API |
| GraphQL | "graphql" | GraphQL API |
| MCP | "mcp" | Model Context Protocol |
| A2A | "a2a" | Agent-to-Agent protocol |
| Custom(String) | (raw string) | Any custom protocol identifier |

## Configuration Entities

### AgentConfig

Top-level YAML configuration file structure.

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| defaults | AgentDefaults | No | Global defaults for inheritance |
| agents | Vec\<AgentDefinition\> | Yes | At least 1 agent definition |

### AgentDefaults

Global defaults that agent definitions inherit from.

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| provider | String | No | Default provider name |
| auth | AuthConfig | No | Default auth configuration |
| endpoints | EndpointDefaults | No | Default endpoint settings |
| capabilities | Capabilities | No | Default capabilities |
| limits | Limits | No | Default limits |
| extensions | JSON Value | No | Default extensions |

**Inheritance rules**:
- Agent-specific values override defaults
- Nested objects merge field-by-field (not wholesale replacement)
- Vec fields (endpoints, auth methods) are NOT merged - agent-level replaces default
- Missing agent fields fall back to default values
- Type safety preserved throughout merging

### AgentDefinition

A single agent entry in the YAML configuration (pre-inheritance).

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| name | String | Yes | Non-empty |
| description | String | Yes | Non-empty |
| provider | String | No | Inherits from defaults if absent |
| endpoints | Vec\<EndpointDefinition\> | Yes | At least 1 endpoint |
| capabilities | Capabilities | No | Inherits from defaults if absent |
| limits | Limits | No | Inherits from defaults if absent |
| security | Security | No | Inherits from defaults if absent |
| extensions | JSON Value | No | Inherits from defaults if absent |

## Cache Entities

### CacheEntry

A stored AX record within the cache.

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| document | AgentExchangeDocument | Yes | The cached AX document |
| domain | String | Yes | The domain this record belongs to |
| expires_at | SystemTime | Yes | TTL expiration timestamp |
| fetched_at | SystemTime | Yes | When the record was fetched |
| last_accessed | SystemTime | Yes | For LRU tracking |
| cache_hit_count | u64 | Yes | Access counter |

**State transitions**:
- **Fresh**: expires_at > now. Served from cache.
- **Expired**: expires_at <= now. Triggers re-fetch on next access.
- **Evicted**: Removed by LRU when cache reaches max_entries.

### CacheStats

Atomic counters for cache observability.

| Field | Type | Description |
|-------|------|-------------|
| total_entries | AtomicUsize | Current number of cached entries |
| hit_count | AtomicU64 | Total cache hits |
| miss_count | AtomicU64 | Total cache misses |
| eviction_count | AtomicU64 | Total LRU evictions |
| memory_usage_bytes | AtomicUsize | Estimated memory usage |

## OAuth Provider Templates

### OAuthProvider (trait)

| Method | Input | Output | Description |
|--------|-------|--------|-------------|
| generate_endpoints | OAuthConfig | OAuthEndpoints | Generate provider-specific endpoints |
| provider_name | - | &str | Provider identifier |

### Provider URL Patterns

| Provider | Issuer | Auth Endpoint | Token Endpoint |
|----------|--------|---------------|----------------|
| Okta | `https://{domain}` | `https://{domain}/oauth2/authorize` | `https://{domain}/oauth2/token` |
| Auth0 | `https://{domain}/` | `https://{domain}/authorize` | `https://{domain}/oauth/token` |
| Generic (RFC 8414) | `https://{domain}` | `https://{domain}/authorize` | `https://{domain}/token` |
